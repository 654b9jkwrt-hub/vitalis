# 1 · لوحة اليوم

**الغرض:** تجيب عن سؤالها الدائم — «كيف يسير اليوم؟» — **بلا نقرة واحدة.**

### التخطيط

```
┌──────────────────────────────────────────────────────────┐
│ 🔍 ابحث باسم أو رقم…                      [+ مريض جديد] │
├────────────┬─────────────────────────────────────────────┤
│            │  اليوم — السبت ٨ آب                         │
│ ● اليوم    │  ٧ مرضى · ٣ انتهوا · ٤٢٠٬٠٠٠ ل.س           │
│ 📅 التقويم │  ─────────────────────────────────────────  │
│ ☎ اتصالات ⑤│  ⚠ انتهى — لم يُحاسب (١)                    │
│ 💰 الصندوق │    ٨:٣٠  ريم خوري   كشف   ٥٠٬٠٠٠   [قبض]  │
│ 📋 الديون ④│  ─────────────────────────────────────────  │
│            │  ● في الانتظار (٢)     ⠿ اسحب لترتيب الدور │
│            │    ⠿ ٩:٣٠ سامر الأحمد  مراجعة  ينتظر ١٢ د    │
│            │    ⠿ ١٠:٠٠ سلمى حداد  كشف    ينتظر ٤ د     │
│            │  ─────────────────────────────────────────  │
│            │  ◐ عند الطبيب (١)                          │
│            │    ٩:٠٠ أحمد عيسى   ضماد   مشمول           │
│            │  ─────────────────────────────────────────  │
│            │  ○ لم يصل بعد (٣)                          │
│            │    ١١:٠٠ يوسف مراد  مراجعة   [وصل]         │
│            │  ─────────────────────────────────────────  │
│            │  ✓ خرج (٢)                          ▸       │
└────────────┴─────────────────────────────────────────────┘
```

### ترتيب المجموعات — قرار مقصود

| # | المجموعة | لماذا هنا |
|---|---|---|
| 1 | **انتهى — لم يُحاسب** | أكثر ما يُنسى في العيادات. المال يخرج من الباب |
| 2 | **في الانتظار** | من تديره الآن |
| 3 | **عند الطبيب** | للعلم فقط — لا فعل مطلوب |
| 4 | **لم يصل بعد** | استعداد |
| 5 | **خرج** | مطوي — أُنجز وانتهى |

**القاعدة:** الترتيب بالإلحاح لا بالزمن. من انتهى ولم يدفع أهم ممن سيأتي بعد ساعتين.

### الأفعال المباشرة من الصف

| الحالة | الزر الظاهر | النقرات |
|---|---|---|
| لم يصل | `[وصل]` | 1 |
| في الانتظار | `⠿` سحب · `[⋯]` | — |
| انتهى ولم يُحاسب | `[قبض]` | 1 |
| أي حالة | نقرة على الاسم ← الملف الإداري | 1 |

### ترتيب الدور بالسحب

- **الافتراضي:** حسب وقت الموعد.
- **السحب:** إمساك `⠿` وتحريك. وسهمان صغيران لمن لا يحب السحب.
- **مؤشر الانتظار:** «ينتظر ٢٥ د» — يتحول للكهرماني بعد 20 دقيقة، وللأحمر بعد 40.
- **لا اعتراض من النظام** إن قدّمت من وصل متأخرًا. هي ترى الصالة والنظام لا يراها.

### الحالات

| الحالة | العرض |
|---|---|
| يوم فارغ | «لا مواعيد اليوم» + `[+ أضف موعدًا]` |
| كل المرضى خرجوا | «انتهى اليوم — ٧ مرضى · ٤٢٠٬٠٠٠» + `[إقفال اليوم]` |
| مريض ينتظر أكثر من 40 دقيقة | صفه بخلفية كهرمانية خفيفة |
| الطبيب غائب | شريط علوي: «الطبيب غير متصل» — تعمل بشكل طبيعي |

# 2 · إضافة مريض / حجز سريع

**الغرض:** إنشاء مريض وحجز موعد **أثناء المكالمة الهاتفية**، لا بعدها.

### التخطيط — طبقة واحدة، لا صفحة

```
┌─ مريض جديد ────────────────────────────────────┐
│ الاسم *      [________________________]        │
│ الهاتف *     [________________________]        │
│                                                │
│ ▸ بيانات إضافية (اختياري)                      │
│                                                │
│ موعد؟   [اليوم] [الغد] [تاريخ آخر] [بلا موعد]  │
│                                                │
│                        [حفظ]      [حفظ وآخر]   │
└────────────────────────────────────────────────┘
```

### القواعد

1. **حقلان إلزاميان فقط:** الاسم والهاتف. حل مباشر لنقطة الاحتكاك الأولى من المرحلة 1.
2. **البيانات الإضافية مطوية:** العمر، الجنس، العنوان، جهة التحويل. تُملأ متى سنحت الفرصة.
3. **الموعد جزء من البطاقة نفسها** — لا شاشة ثانية.
4. **المؤشر يقف في حقل الاسم تلقائيًا.** `Tab` ثم `Enter` ينهي كل شيء بلا فأرة.
5. **«حفظ وآخر»** يحفظ ويفتح بطاقة فارغة — لإدخال عدة مرضى متتالين.

### كشف التكرار

عند كتابة اسم أو رقم قريب من موجود:

> ⚠ يوجد مريض باسم مشابه: **سامر الأحمد · ٠٩٩١٢٣٤٥٦٧** — [هو نفسه] [مريض جديد]

**يقترح ولا يمنع.** الأسماء المتشابهة كثيرة في سوريا، والقرار للسكرتيرة لا للنظام.

# 3 · القبض

**الغرض:** أكثر فعل مالي تكرارًا. يجب أن ينتهي في ثوانٍ.

### التخطيط

```
┌─ قبض من ريم خوري ──────────────────────────────┐
│                                                │
│   المستحق          ٥٠٬٠٠٠ ل.س                  │
│                                                │
│   المقبوض     [    ٥٠٬٠٠٠    ]                 │
│                                                │
│   [المبلغ كاملًا]                              │
│                                                │
│                              [تأكيد القبض]     │
└────────────────────────────────────────────────┘
```

### القواعد

| البند | القاعدة |
|---|---|
| **الحقل معبّأ مسبقًا** بالمبلغ الكامل | الحالة الغالبة تنتهي بنقرة واحدة |
| **لا يمنع أي مبلغ** | تُدخل ما قُبض فعلًا (قرار المرحلة 1) |
| **الفرق يصبح دينًا تلقائيًا** | بلا سؤال ولا إذن |
| **إشعار صامت للطبيب فورًا** | تراه هي كسطر تأكيد صغير: «أُبلغ الطبيب» |
| **دفعة أكبر من المستحق** | تُقبل، وتُسجَّل رصيدًا للمريض |

### بعد التأكيد

يتحول الصف في لوحة اليوم إلى `✓ خرج · ٥٠٬٠٠٠` وينتقل لمجموعة «خرج». **بلا شاشة تأكيد ولا رسالة نجاح** — النتيجة نفسها هي الرسالة.

### قبض دين قديم

من شاشة الديون أو ملف المريض، البطاقة نفسها بفارق واحد: تعرض الدين وتاريخ نشوئه، وتقبل السداد الجزئي.

# 4 · التقويم

**الغرض:** التخطيط المستقبلي — الوجه الثاني للمواعيد، منفصل عن «اليوم» (اكتشاف المرحلة 1).

### التخطيط

```
┌─ آب ٢٠٢٦ ─────────────────── [أسبوع] [شهر] ──┐
│                                               │
│  السبت ٨    الأحد ٩    الاثنين ١٠   الثلاثاء ١١│
│  ─────────  ─────────  ──────────  ───────────│
│  ٩:٠٠ أحمد  ٩:٠٠ ▫     ٩:٠٠ مروان  ٩:٠٠ ▫    │
│  ٩:٣٠ نبيل  ٩:٣٠ سامر  ٩:٣٠ ▫      🔪 عملية  │
│  ١٠:٠٠ سلمى ١٠:٠٠ ▫    ١٠:٠٠ ▫     ─────────  │
│  ١٠:٣٠ ▫    ...                               │
└───────────────────────────────────────────────┘
```

### القواعد

| البند | القاعدة |
|---|---|
| **الحجز بنقرة على خانة فارغة** | تفتح بطاقة صغيرة: بحث عن مريض أو إنشاء جديد |
| **النقل بالسحب** | سحب موعد إلى خانة أخرى ← يُنقل، مع تسجيل الحدث |
| **الأيام المغلقة** | مظللة، والحجز فيها ممكن مع تنبيه (قرار المرحلة 3: ⚠ موثّق) |
| **يوم العملية** | يُوسم بأيقونة `🔪` — والمواعيد تُقلَّص تلقائيًا حوله |
| **مدة الموعد** | تختلف بنوع الزيارة: كشف 30 د · مراجعة 15 د · ضماد 10 د (قابلة للتعديل) |

### ما لا تراه السكرتيرة هنا

اسم العملية أو تفاصيلها. ترى: `🔪 عمل جراحي — د. [اسم الطبيب]` فقط (قرار المرحلة 3).

# 5 · اتصالات الغد

**الغرض:** تحويل الإلغاءات من مفاجأة صباحية إلى معلومة تُعرف مساء اليوم السابق.

### التخطيط

```
┌─ اتصالات — مواعيد الأحد ٩ آب ─────────────────┐
│  ٦ مواعيد · ٢ لم يُتصل بهم                     │
│                                                │
│  سامر حلاق     ٠٩٩٩٩٩٩٩٩٩   ٩:٣٠              │
│     [✓ تأكد]  [☎ لم يرد]  [✕ اعتذر]           │
│                                                │
│  مروان علي     ٠٩٨٨٨٨٨٨٨٨   ١٠:٠٠   ✓ تأكد    │
│  ليلى نصر      ٠٩٧٧٧٧٧٧٧٧   ١٠:٣٠   ☎ لم يرد  │
│                                                │
│  ─────────────────────────────────────────     │
│  اتصالات أخرى                                  │
│  📋 ٤ مدينين      ▸                            │
│  ⏳ ٢ لم يحضروا نتائج  ▸                       │
└────────────────────────────────────────────────┘
```

### الحالات الثلاث

| الحالة | ما يحدث |
|---|---|
| **✓ تأكد** | يبقى الموعد، ويُوسم بعلامة تأكيد يراها الطبيب غدًا |
| **☎ لم يرد** | يبقى في القائمة لتعاود الاتصال. عدّاد المحاولات يظهر |
| **✕ اعتذر** | **يُلغى الموعد فورًا من هنا** — وتتحرر الخانة في التقويم |

### الفائدة الجانبية

عند إلغاء موعد، يعرض النظام مباشرة:

> تحرر الأحد ٩:٣٠ — يوجد ٣ مرضى في قائمة الانتظار — [عرضهم]

**هكذا يتحول الإلغاء من خسارة إلى فرصة.**

# 6 · ملف المريض — النسخة الإدارية

**الغرض:** ما تحتاجه السكرتيرة من ملف المريض، بلا حرف طبي واحد.

### التخطيط

```
┌────────────────────────────────────────────────┐
│ سامر الأحمد                              [⋯]     │
│ ٤٢ سنة · ٠٩٩١٢٣٤٥٦٧ · حماة                    │
│ 💰 دين ٢٠٬٠٠٠                                  │
├────────────────────────────────────────────────┤
│ ملاحظة الطبيب                                  │
│ «يحضر التحاليل معه في الزيارة القادمة»         │
├────────────────────────────────────────────────┤
│ المواعيد                                       │
│  القادم: الثلاثاء ١٢ آب · ٩:٣٠                │
│  🔪 عمل جراحي مقرر — ١٢ آب                    │
├────────────────────────────────────────────────┤
│ الزيارات                                       │
│  ٢٤ تموز  مراجعة        ٥٠٬٠٠٠  ✓            │
│  ١٠ تموز  كشف           ٧٠٬٠٠٠  ✓            │
│  ٢ حزيران زيارة قصيرة   مشمول                 │
├────────────────────────────────────────────────┤
│ الحساب                                         │
│  إجمالي المستحق  ١٤٠٬٠٠٠                       │
│  المقبوض         ١٢٠٬٠٠٠                       │
│  الدين            ٢٠٬٠٠٠        [قبض]         │
└────────────────────────────────────────────────┘
```

### ما تراه وما لا تراه

| ✅ ترى | ❌ لا ترى |
|---|---|
| البيانات الإدارية | الشكوى والفحص والتشخيص |
| تواريخ الزيارات وأنواعها | محتوى أي زيارة |
| ملاحظة الطبيب الإدارية | التحذيرات الطبية (الحساسية) |
| وجود عمل جراحي وتاريخه | نوع العمل الجراحي |
| كل الحساب المالي | الوصفات والطلبات والمرفقات |

# 7 · الديون

**الترتيب:** حسب القِدَم لا المبلغ — الدين القديم أخطر من الكبير.

```
┌─ الديون ─────────────── ١٤ مريضًا · ٦٤٠٬٠٠٠ ─┐
│                                               │
│ ريم خوري      ٢٠٬٠٠٠   منذ ٤٥ يومًا  [☎][قبض]│
│ أحمد عيسى      ٥٬٠٠٠   منذ ٣٠ يومًا  [☎][قبض]│
│ سلمى حداد     ٢٠٬٠٠٠   منذ ١٢ يومًا  [☎][قبض]│
└───────────────────────────────────────────────┘
```

**كل سطر:** الاسم · المبلغ · القِدَم · آخر زيارة · زر اتصال · زر قبض.

**الاتصال:** يفتح رقم المريض ويسجل محاولة الاتصال وتاريخها — لتعرف من كُلّم ومن لا.

**الإعفاء غير متاح لها** (قرار المرحلة 3) — يظهر الزر معطلًا بتلميح: «الإعفاء من الطبيب».

# 8 · الصندوق وإقفال اليوم

**الغرض:** لحظة الثقة اليومية. أهم شاشة مالية في النظام.

### الصندوق أثناء اليوم

```
┌─ الصندوق — السبت ٨ آب ────────────────────────┐
│                                               │
│        ٤٢٠٬٠٠٠ ل.س                            │
│        من ٧ مرضى                              │
│                                               │
│  ٨:٣٠  ريم خوري      ٣٠٬٠٠٠   ⚠ ناقص ٢٠٬٠٠٠  │
│  ٩:٠٠  أحمد عيسى     ٢٥٬٠٠٠                   │
│  ٩:٣٠  سامر الأحمد     ٥٠٬٠٠٠                   │
│  …                                            │
│                                               │
│                          [إقفال اليوم]        │
└───────────────────────────────────────────────┘
```

### بطاقة الإقفال — المطابقة النقدية

```
┌─ إقفال يوم السبت ٨ آب ────────────────────────┐
│                                               │
│  المسجّل في النظام        ٤٢٠٬٠٠٠             │
│                                               │
│  النقد الفعلي في يدك   [ ___________ ]        │
│                                               │
│  ─────────────────────────────────────        │
│  الفرق                    ٠                   │
│                                               │
│  ملاحظة (اختياري) ______________              │
│                                               │
│                        [تأكيد الإقفال]        │
└───────────────────────────────────────────────┘
```

### قواعد الإقفال

| الحالة | السلوك |
|---|---|
| **الفرق = صفر** | لون أخضر، إقفال مباشر |
| **الفرق ≠ صفر** | لون كهرماني + **حقل الملاحظة يصبح إلزاميًا** |
| **بعد الإقفال** | لا تستطيع السكرتيرة تعديل شيء من اليوم — فقط الطبيب |
| **مسودات مفتوحة عند الطبيب** | تنبيه للطبيب لا لها — لا يمنعها من الإقفال |
| **إقفال منسي** | إن فُتح النظام في اليوم التالي دون إقفال أمس، يظهر تذكير أول شيء |

**لماذا الملاحظة إلزامية عند الفرق؟** لأن الفرق بلا تفسير يتحول إلى سؤال محرج بعد أسبوع لا يذكر أحد جوابه. الملاحظة تحمي السكرتيرة قبل أن تحمي الطبيب.

### ما تراه بعد الإقفال

ملخص لا يتغير: `تم إقفال السبت ٨ آب · ٤٢٠٬٠٠٠ · بلا فروقات`

### 9.1 قائمة الانتظار — الشكل البسيط

**ما هي:** قائمة أسماء وأرقام تضيفها السكرتيرة يدويًا. لا أكثر.

```
┌─ قائمة الانتظار ──────────────────── ٣ ───────┐
│                                               │
│  سامي درويش   ٠٩٩٥٥٥٥٥٥٥  «يريد موعدًا قريبًا»│
│  هدى العلي    ٠٩٩٤٤٤٤٤٤٤  «صباحًا فقط»       │
│  خالد منصور   ٠٩٩٣٣٣٣٣٣٣                     │
│                                               │
│                            [+ أضف اسمًا]      │
└───────────────────────────────────────────────┘
```

| البند | القاعدة |
|---|---|
| **الحقول** | اسم · هاتف · ملاحظة حرة (اختيارية) |
| **الإضافة** | من أي مكان: من قائمة الانتظار، أو أثناء مكالمة، أو من ملف مريض |
| **عند إلغاء موعد** | يظهر سطر واحد: `تحرر الأحد ٩:٣٠ — ٣ في قائمة الانتظار [عرض]` |
| **لا ذكاء ولا مطابقة تلقائية** | السكرتيرة تقرر من تتصل به — قد يكون الثالث أنسب من الأول |
| **الحذف** | يدوي، أو تلقائيًا عند حجز موعد لنفس المريض |

**لماذا بلا ذكاء؟** أي مطابقة آلية ستحتاج تفضيلات وقيودًا وأوقاتًا مفضلة — تعقيد كبير لفائدة تعطيها نظرة السكرتيرة في ثانيتين. الوحدة تُبنى في يوم بدل أسبوع.

---

### 9.2 لا إيصال ورقي

**ما يحل محله:**

| البديل | التفصيل |
|---|---|
| **السجل في ملف المريض** | كل دفعة بتاريخها ومبلغها ومن قبضها — يراها الطبيب والسكرتيرة |
| **عند الطلب النادر** | زر `طباعة إيصال` موجود لكنه يطبع على طابعة الطبيب — يُستخدم للمرضى الذين يحتاجونه لجهة عمل أو تأمين |
| **الأثر التصميمي** | حذفنا قالب طباعة كاملًا من المرحلة 6ج — بقيت ثلاثة قوالب لا أربعة |

**مكسب جانبي:** لا حاجة لطابعة ثانية ولا لورق حراري ولا لصيانة جهاز إضافي في عيادة جديدة.

# 1 · شاشة اليوم — الرئيسية

**الغرض:** أول ما يراه الطبيب عند فتح النظام، وحيث يعود بعد كل زيارة.

### التخطيط

```
┌────────────────────────────────────────────────────────────┐
│ [شعار] عيادة د. [اسم الطبيب]    🔍 بحث…      [🔔] [👤] │
├────────────────────────────────────────────┬───────────────┤
│                                            │ اليوم         │
│   السبت ٨ آب                               │ ───────────   │
│   ٧ مرضى · ٣ انتهوا                        │ ٩:٠٠ أحمد ✓  │
│                                            │ ٩:٣٠ نبيل ●  │
│   ┌──────────────────────────────────┐     │ ١٠:٠٠ سلمى   │
│   │  التالي                          │     │ ١٠:٣٠ يوسف   │
│   │  سامر الأحمد · 42 سنة              │     │               │
│   │  مراجعة · ينتظر منذ ١٢ دقيقة     │     │ ───────────   │
│   │  ⚠ حساسية بنسلين                 │     │ ⏳ تحتاج      │
│   │                    [ابدأ الزيارة] │     │    انتباهك ③ │
│   └──────────────────────────────────┘     │               │
│                                            │               │
│   تحتاج انتباهك                            │               │
│   ┌──────────────────────────────────┐     │               │
│   │ ⏳ سلمى حداد — نتيجة لم تصل      │     │               │
│   │ 📅 يوسف مراد — عملية بلا موعد    │     │               │
│   │ ✎ زيارة غير مكتملة — أمس         │     │               │
│   └──────────────────────────────────┘     │               │
└────────────────────────────────────────────┴───────────────┘
```

### القرار المحوري — بطاقة «التالي»

**لماذا بطاقة واحدة كبيرة لا قائمة؟** لأن الطبيب في هذه اللحظة لا يريد خيارات — يريد فعلًا واحدًا: أن يبدأ. القائمة تفرض قرارًا («من أختار؟») والقرار قد اتُّخذ أصلًا: السكرتيرة رتّبت الدور.

**محتوى البطاقة:** الاسم · العمر · نوع الزيارة · مدة الانتظار · التحذيرات الطبية · زر واحد.

**التحذيرات الطبية تظهر قبل الدخول** — لتعرف الحساسية قبل أن تفكر في الوصفة، لا بعدها.

### الحالات

| الحالة | ما يُعرض |
|---|---|
| **يوجد منتظر** | بطاقة «التالي» + المعلّقات |
| **لا أحد ينتظر** | «لا أحد ينتظر الآن» + المعلّقات تتصدر الشاشة |
| **انتهى اليوم** | ملخص اليوم: عدد المرضى، الدخل، ما بقي معلّقًا |
| **قبل بدء الدوام** | مواعيد اليوم كاملة + تنبيه إن كان فيها ما يحتاج تحضيرًا |
| **أول يوم (عيادة جديدة)** | «لا مواعيد بعد — ابدأ بإضافة أول مريض» + زر |

### الأفعال

| الفعل | النقرات |
|---|---|
| بدء زيارة المريض التالي | **1** |
| فتح مريض آخر من القائمة | **1** |
| فتح المعلّقات | **1** |
| البحث | **1** أو `⌘K` |

# 2 · ملف المريض

**الغرض:** كل ما يخص مريضًا واحدًا في مساحة واحدة متصلة. **هذا هو التطبيق.**

### التخطيط

```
┌─ الرأس (ثابت عند التمرير) ─────────────────────┐
│ سامر الأحمد                              [⋯]     │
│ ٤٢ سنة · ذكر · ٠٩٩١٢٣٤٥٦٧ · حماة              │
│ ⚠ حساسية بنسلين · مميعات دم                    │
├─ شريط الحالة ──────────────────────────────────┤
│ 📁 فتق إربي أيمن · مفتوحة منذ ٢٠ يومًا  [تغيير]│
├────────────────────────────────────────────────┤
│ ● الزيارة الجارية        ← إن كانت مفتوحة      │
│ ● آخر زيارة              ← مفتوحة ومقروءة      │
│ ● الأعمال الجراحية       ← إن وُجدت            │
│ ● المرفقات               ← إن وُجدت            │
│ ● الزيارات السابقة       ← مطوية، سطر لكل زيارة│
│ ● الحالات الأخرى         ← مطوية               │
│ ● الحساب                 ← رصيد ودفعات         │
└────────────────────────────────────────────────┘
```

### قواعد الترتيب

1. **التحذيرات الطبية في الرأس، لا تُطوى ولا تُخفى ولا تحتاج نقرة.** إن لم توجد، يختفي السطر بالكامل — لا مساحة فارغة.
2. **«آخر زيارة» مفتوحة دائمًا.** هذا قرار من المرحلة 1 يحلّ نقطة الاحتكاك الثالثة بصفر نقرات.
3. **كل ما قبلها سطر واحد** يُفتح بنقرة: `▸ ١٠ تموز — كشف — فتق إربي أيمن`
4. **الأقسام الفارغة لا تظهر.** مريض بلا مرفقات لا يرى عنوان «المرفقات».

### الرأس عند التمرير

يتقلّص إلى شريط رفيع: `سامر الأحمد · ٤٢ · ⚠` — الاسم والتحذير يبقيان مرئيين دائمًا مهما نزلت.

### قائمة `⋯`

| الفعل | ملاحظة |
|---|---|
| تعديل بيانات المريض | |
| إضافة تحذير طبي | حساسية، مرض مزمن، دواء دائم |
| فتح حالة جديدة | ← يبدأ سياقًا جديدًا |
| طباعة ملخص الملف | |
| أرشفة المريض | مع تأكيد |

### حالات خاصة

| الحالة | العرض |
|---|---|
| **مريض جديد بلا زيارات** | الرأس + زر واحد كبير: «ابدأ الزيارة الأولى» |
| **مريض عليه دين** | شارة كهرمانية في الرأس: `دين ٢٠٬٠٠٠` |
| **حالة مغلقة** | الشريط رمادي: `📁 فتق إربي — مغلقة في ٥ آب` |
| **عدة حالات مفتوحة** | الشريط يعرض النشطة ويشير: `+ حالة أخرى` |

# 3 · محرر الزيارة

**الغرض:** تدوين ما يجري الآن، بأقل نظر ممكن إلى الشاشة.

### التخطيط

```
┌─ الزيارة الجارية · مراجعة · ٩:٤٢ ──────────────┐
│                                                │
│  ✎ التقاط سريع                                 │
│  ┌──────────────────────────────────────────┐  │
│  │ أحضر التحاليل — الخضاب ١٣.٢              │  │
│  │ التخثر طبيعي                             │  │
│  │ الجرح القديم سليم                        │  │
│  │ مؤهل للعملية — نحدد موعدًا               │  │
│  └──────────────────────────────────────────┘  │
│                                                │
│  ▸ الحقول المنظمة                              │
│  ▸ إجراء في العيادة                            │
│                                                │
│  [مسودة · حُفظت الآن]         [إنهاء الزيارة]  │
└────────────────────────────────────────────────┘
```

### لوح الالتقاط

| البند | المواصفة |
|---|---|
| **المؤشر** | يقف داخله تلقائيًا فور بدء الزيارة — لا نقرة |
| **الحجم** | يبدأ بأربعة أسطر ويتمدد مع الكتابة |
| **الحفظ** | كل حرف يُحفظ فورًا. مؤشر خافت: «حُفظت الآن» |
| **بلا تنسيق** | لا عناوين ولا قوائم ولا خطوط عريضة — نص خام سريع |

### التوزيع على الحقول

**متى يظهر:** عند مغادرة اللوح (النقر خارجه)، أو بضغط زر «وزّع».

**كيف يعمل:** يظهر بجانب كل سطر شريط صغير من أربعة أزرار — `شكوى · فحص · تشخيص · خطة`. نقرة تنقل السطر إلى حقله.

**القاعدة الحاكمة:** إن لم توزّع شيئًا، **النص يبقى كاملًا ويُحفظ كسجل صالح**. التوزيع ترقية اختيارية لا شرط.

### الحقول المنظمة (مطوية افتراضيًا)

| الحقل | ملاحظة |
|---|---|
| الشكوى | نص حر |
| القصة المرضية | نص حر |
| الفحص السريري | نص حر |
| **التشخيص** | نص حر **مع اقتراحات أثناء الكتابة** — الحقل الوحيد الذي يقترح |
| الخطة | نص حر |

### إجراء في العيادة (مطوي)

يُفتح بنقرة داخل الزيارة نفسها — **بلا إنهاء زيارة وفتح أخرى** (قاعدة من المرحلة 2).

| الحقل | |
|---|---|
| نوع الإجراء | مع اقتراحات من إجراءاتك السابقة |
| التخدير | موضعي / بلا |
| وصف مختصر | |
| متابعة | «نزع قطب بعد ٧ أيام» ← يولّد اقتراح موعد في بطاقة الاختتام |

### أنواع الزيارة — سلوك مختلف لكل نوع

| النوع | ما يُفتح |
|---|---|
| **كشف** | لوح الالتقاط + الحقول مطوية |
| **مراجعة** | لوح الالتقاط + ملخص آخر زيارة فوقه مباشرة |
| **زيارة قصيرة** | **لا محرر إطلاقًا** — انظر أدناه |
| **زيارة إجراء** | لوح الالتقاط + قسم الإجراء مفتوح |

### الزيارة القصيرة — أسرع فعل في النظام

من ملف المريض، زر واحد: `+ زيارة قصيرة`

يفتح قائمة صغيرة: `ضماد · نزع قطب · مراجعة سريعة`

نقرة على أحدها ← **انتهى**. تُسجَّل الزيارة بتاريخها ونوعها، وتُحسب مجانيتها تلقائيًا (قرار ②).

**نقرتان. بلا حقول. بلا بطاقة اختتام** — إلا إن كانت مسعّرة، فتظهر بطاقة مصغّرة بحقل المبلغ وحده.

### حالات الحفظ

| الحالة | العرض |
|---|---|
| تُكتب الآن | «يُحفظ…» خافت |
| حُفظت | «حُفظت الآن» ← يتلاشى بعد ثانيتين |
| مسودة قديمة | شارة كهرمانية: `مسودة منذ أمس` |

# 4 · بطاقة الاختتام

**الغرض:** لحظة يتقاطع فيها الطبي والمالي والإداري. **إن ثقلت، ثقل النظام كله.**

### التخطيط

طبقة تنزلق من الأسفل (Sheet)، عرضها 480، استدارتها العلوية 20.

```
┌────────────────────────────────────────┐
│              ▬▬▬▬                      │
│      إنهاء زيارة سامر الأحمد             │
│      مراجعة · السبت ٨ آب               │
├────────────────────────────────────────┤
│ 💊 الوصفة                    [+ إضافة] │
│ 🧪 طلبات خارجية              [+ إضافة] │
│ 📅 الموعد القادم        [بعد أسبوع ▾] │
│ 💰 المبلغ المستحق          [ ٥٠٬٠٠٠ ] │
├────────────────────────────────────────┤
│  [إنهاء وطباعة]          [إنهاء فقط]   │
└────────────────────────────────────────┘
```

### قواعد الأسطر الأربعة

| السطر | القاعدة |
|---|---|
| **الوصفة** | اختيارية. إن أُضيفت، يتحول السطر إلى ملخص: `٣ أدوية ▸` |
| **الطلبات** | اختيارية. `تعداد دم · وظائف كلية ▸` |
| **الموعد القادم** | **مقترح لا مفروض.** يُشتق من: نوع الزيارة، الإجراء المنفَّذ، ما كتبته في الخطة |
| **المبلغ** | **إلزامي.** لا إنهاء بحقل فارغ |

### منطق المبلغ

```
هل هي زيارة قصيرة لمريض له عمل جراحي عندي؟
  → نعم: «مشمول — ٠» تلقائيًا، قابل للتغيير
  → لا:  اقتراح آخر مبلغ استخدمته لهذا النوع
```

**يقبل الصفر** (زيارة مجانية) — لكن **لا يقبل الفراغ**. الفرق جوهري: الصفر قرار، والفراغ نسيان.

### الأزرار

| الزر | ما يفعل |
|---|---|
| **إنهاء وطباعة** | يغلق الزيارة · يطبع الوصفة والطلبات · يرسل المستحق للسكرتيرة · يحجز الموعد · يعيدك لشاشة اليوم |
| **إنهاء فقط** | كل ما سبق عدا الطباعة |
| **Esc** | يغلق البطاقة والزيارة **تبقى مسودة سليمة** |

### التحقق قبل الإغلاق

| الحالة | السلوك |
|---|---|
| المبلغ فارغ | لا يُنهي — يتوهج الحقل ويقف فيه المؤشر |
| لا يوجد تشخيص منظّم | **اقتراح واحد صغير** يُقبل بنقرة أو يُتجاهل — **لا يمنع الإنهاء** |
| اللوح فارغ تمامًا | تنبيه لطيف: «الزيارة بلا أي تدوين — إنهاء؟» مع خيار المتابعة |

# 5 · محرر الوصفة

**الغرض:** أسرع طريق من قرار الدواء إلى ورقة مطبوعة.

### التخطيط

```
┌─ وصفة سامر الأحمد ───────────────────────────────┐
│ 🔍 اسم الدواء…                                 │
│ ┌────────────────────────────────────────────┐ │
│ │ ⭐ قوالبي                                  │ │
│ │   ما بعد عملية فتق        (٤ أدوية)        │ │
│ │   التهاب جرح              (٣ أدوية)        │ │
│ │ ── أدويتي ──                               │ │
│ │   Augmentin 1g            ١×٢ · ٧ أيام     │ │
│ │   Brufen 600              ١×٣ · ٥ أيام     │ │
│ └────────────────────────────────────────────┘ │
├────────────────────────────────────────────────┤
│ ١· Augmentin 1g      ١×٢ · ٧ أيام        [✕]  │
│ ٢· Brufen 600        ١×٣ · ٥ أيام        [✕]  │
│                                                │
│ + سطر حر…                                      │
├────────────────────────────────────────────────┤
│ ملاحظات للمريض: ______________________         │
│                          [تم]   [حفظ كقالب]    │
└────────────────────────────────────────────────┘
```

### البنية الثلاثية (قرارك من المرحلة 2)

| الطبقة | السرعة | كيف تعمل |
|---|---|---|
| **القوالب** | الأسرع — نقرة واحدة | وصفة كاملة تُطبَّق ثم تُعدَّل |
| **أدويتي** | نقرتان | دواء مفرد بجرعته المعتادة المحفوظة |
| **السطر الحر** | كتابة | لا حواجز — أي نص |

**الترتيب في القائمة مقصود:** القوالب أولًا لأنها الأسرع. النظام يدفعك نحو الأسرع دون أن يمنعك من الأبطأ.

### كيف تنمو قائمة الأدوية

أول مرة تكتب `Augmentin 1g` بجرعة `١×٢ · ٧ أيام` → يُحفظ الدواء بجرعته. المرة التالية يظهر جاهزًا.

**لا شاشة «إدارة الأدوية» يجب ملؤها قبل الاستخدام.** القائمة تُبنى من عملك.

### حفظ كقالب

بعد كتابة وصفة، زر واحد يحوّلها قالبًا باسم تختاره. **هكذا تُبنى القوالب: من وصفة حقيقية، لا من شاشة إعداد.**

# 6 · محرر الطلبات الخارجية

بنية مطابقة للوصفة، بثلاث طبقات: **قوالبي · فحوصي · سطر حر**.

**قوالب متوقعة:** «ما قبل العملية»، «تقييم أولي»، «متابعة سكري».

**الفرق الوحيد عن الوصفة:** كل طلب يولّد **معلّقة** تُتابَع حتى تصل النتيجة (وحدة 9).

# 7 · العمل الجراحي

**الغرض:** كيان مستقل يمتد عبر الزمن — لا سطر داخل زيارة (قرار المرحلة 2).

### الإنشاء — من داخل الزيارة

```
┌─ عمل جراحي جديد ───────────────────────────────┐
│ النوع:   [○ إجراء صغير — العيادة]              │
│          [● عملية كبرى — المشفى]               │
│                                                │
│ العملية:  ________________  (اقتراحات)         │
│ الحالة:   [● مقرر]  [○ منفّذ]                  │
│ التاريخ:  [__________]  ← يمكن تركه فارغًا     │
│ أجر الجراح: [___________]                      │
│ ملاحظات:  ________________________             │
└────────────────────────────────────────────────┘
```

### الحالات الثلاث

| الحالة | ما يترتب |
|---|---|
| **مقرر** | ← **معلّقة** حتى يُنفَّذ. إن كان بلا تاريخ ← معلّقة أشد إلحاحًا |
| **منفّذ** | ← يفتح متابعة ما بعد العملية · يجعل ضمادات المريض مجانية (قرار ②) |
| **ملغى** | ← يُحفظ مع السبب. لا يُحذف |

### عرض العمل الجراحي في الملف

```
🔪 استئصال فتق إربي أيمن
   مقرر · الثلاثاء ١٢ آب · أجر ٥٠٠٬٠٠٠
   ── الدفعات: ٢٠٠٬٠٠٠ مقبوض · ٣٠٠٬٠٠٠ متبقٍ
   ── الزيارات المرتبطة: ٣
```

**الربط التلقائي:** كل زيارة بعد تاريخ التنفيذ داخل الحالة نفسها تُربط بالعمل الجراحي تلقائيًا.

# 8 · تحتاج انتباهك

**الغرض:** إظهار كل التزام مفتوح. **هذه الشاشة هي ما لا يقدمه الورق ولا معظم البرامج.**

### التخطيط

مجموعات مرتبة بالإلحاح، لا بالتاريخ:

```

### مصادر المعلّقات

| المعلّق | يظهر متى | يُغلق متى |
|---|---|---|
| طلب خارجي | عند إنشائه | عند تأشير «رأيت النتيجة» |
| نتيجة وصلت ولم تُراجَع | تأشير السكرتيرة «أحضر الأوراق» | عند مراجعتك |
| عمل جراحي مقرر | عند إنشائه | عند التنفيذ أو الإلغاء |
| عمل جراحي بلا موعد | عند إنشائه بلا تاريخ | عند تحديد التاريخ |
| دين | عند نشوئه | عند السداد أو الإعفاء |
| حالة خاملة | بلا زيارة مدة يحددها الطبيب | عند زيارة أو إغلاق الحالة |
| زيارة غير مكتملة | مسودة بعد انتهاء الدوام | عند إنهائها |
| فروقات مالية | عند القبض الناقص | عند مراجعتك لها |

### قواعد

1. **كل سطر قابل للفتح مباشرة** — نقرة تفتح المريض في السياق الصحيح.
2. **كل سطر قابل للتأجيل** — «ذكّرني بعد أسبوع». التأجيل ليس تجاهلًا: يعود.
3. **العدّاد على العمود الجانبي** يعرض المتأخر فقط، لا الكل — وإلا صار رقمًا مخيفًا يُتجاهل.
4. **لا يوجد «تم» بلا فعل حقيقي.** المعلّقة تُغلق بحدثها، لا بضغطة إخفاء.

# 9 · المرفقات

**العرض:** شبكة مصغّرات داخل ملف المريض، مرتبة بالتاريخ، كل مرفق موسوم بالزيارة التي أُضيف فيها.

**الإضافة:** سحب ملف إلى النافذة · أو زر «+» يفتح متصفح الملفات.

**العرض الكامل:** نقرة تفتح المرفق ملء الشاشة، مع تكبير وتدوير وتنقل بالأسهم.

**⚠ مؤجَّل للمرحلة 8:** إدخال الصور من الجوال في شبكة بلا إنترنت.

```
آب ٢٠٢٦
الدخل      ٣٬٤٥٠٬٠٠٠

**رسم بياني واحد فقط:** أعمدة الدخل الشهري لآخر 12 شهرًا. لا رسوم دائرية ولا لوحات معقدة.

### 12.2 الديون

قائمة مرتبة **حسب القِدَم** لا المبلغ — لأن الدين القديم أخطر من الكبير.

| التقرير | المحتوى |

### 13.1 شاشة البداية الذكية

| الحالة | ما يُعرض |
|---|---|
| **أول تشغيل في اليوم** | «تحتاج انتباهك» — ملخص المعلّقات قبل انغماسك في المرضى |
| **بعد ذلك** | «اليوم» — في كل فتح أو عودة أو استيقاظ من القفل |
| **إن كانت المعلّقات صفرًا صباحًا** | يتجاوزها مباشرة إلى «اليوم» — لا شاشة فارغة تُهدر نقرة |

**التفصيل الحاسم:** الشاشة الصباحية ليست حاجزًا. زر واحد بارز «ابدأ اليوم»، و`Esc` يفعل الشيء نفسه. المعلّقات تُعرض لتُرى، لا لتُعالَج الآن.

---

### 13.2 التأجيل مع عودة مضمونة

| البند | القاعدة |
|---|---|
| **الخيارات** | غدًا · بعد أسبوع · بعد شهر · تاريخ محدد |
| **بعد التأجيل** | تختفي من القائمة النشطة تمامًا |
| **العودة** | تعود في موعدها **بعلامة**: `مؤجّلة سابقًا` — لتعرف أنك رأيتها من قبل |
| **التأجيل المتكرر** | بعد التأجيل الثالث تُوسَم `مؤجّلة ٣ مرات` بلون كهرماني أغمق |
| **المؤجَّلات** | قسم مطوي أسفل الشاشة: `٤ مؤجّلة ▸` — لا تختفي عن الوجود، فقط عن الطريق |

**لماذا وسم التكرار؟** المعلّقة التي تُؤجَّل ثلاث مرات لا تحتاج تذكيرًا رابعًا — تحتاج قرارًا: إما فعل أو إغلاق نهائي. الوسم يقول لك ذلك بلا وعظ.

### 13.3 أسماء الأدوية — عربي ولاتيني معًا

**القرار:** كل دواء له اسمان مخزّنان، وأنت تقرر لكل دواء ما يظهر في الطباعة.

```
┌─ إضافة دواء لقائمتي ───────────────────────────┐
│ الاسم العربي:    أوغمنتين ١ غ                  │
│ الاسم اللاتيني:  Augmentin 1g     (اختياري)    │
│ الجرعة المعتادة: حبة مرتين يوميًا · ٧ أيام     │
│                                                │
│ في الوصفة المطبوعة يظهر:                       │
│   ○ العربي فقط                                 │
│   ● العربي واللاتيني بجانبه                    │
│   ○ اللاتيني فقط                               │
└────────────────────────────────────────────────┘
```

**قواعد مشتقة:**

1. **البحث يجد الدواء بأي من الاسمين.** تكتب `aug` أو `أوغ` — يظهر الدواء نفسه.
2. **الاختيار يُحفظ مع الدواء للأبد.** تقرره مرة واحدة عند أول استخدام.
3. **الوضع الافتراضي للدواء الجديد:** العربي واللاتيني معًا — الأسلم قبل أن تقرر.
4. **الجرعة والتعليمات بالعربية دائمًا** — «حبة مرتين يوميًا لمدة أسبوع» لا `1x2 7d`. هذه للمريض لا للصيدلي.

**الملاحظة المهنية المسجَّلة:** الاسم اللاتيني يقلل احتمال الخطأ في الصيدلية، خصوصًا في الأدوية متقاربة اللفظ. القرار قرارك لكل دواء — والنظام يجعل الخيارين متاحين بلا كلفة إضافية.

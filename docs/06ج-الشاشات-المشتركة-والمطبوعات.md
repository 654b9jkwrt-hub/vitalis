### القواعد

| البند | القرار |
|---|---|
| **اختيار المستخدم بالبطاقة لا بالكتابة** | مستخدمان فقط — كتابة اسم المستخدم عبث |
| **بعد الاختيار** | حقل كلمة المرور يظهر في مكان البطاقتين |
| **جهاز الطبيب** | يتذكر أنه جهازه — يفتح على بطاقة الطبيب مباشرة |
| **جهاز السكرتيرة** | تُسجّل دخولها مرة صباحًا وتبقى طوال الدوام |
| **بعد ثلاث محاولات خاطئة** | تأخير 30 ثانية — لا حظر دائم يعطل العمل |
| **الشعار والاعتماد** | الشعار في المنتصف، وسطر الاعتماد خافت في الأسفل |

**حالة أول تشغيل (عيادة جديدة):** معالج قصير — بيانات العيادة، كلمتا المرور، أوقات الدوام، الأسعار الأساسية. **أربع شاشات لا أكثر، وكلها قابلة للتخطي والعودة لاحقًا.**

```
┌────────────────────────────────────────────────┐
│                                                │
│                     🔒                         │
│              د. [اسم الطبيب]                     │
│                                                │
│              ○  ○  ○  ○                        │

```

| البند | القرار |
|---|---|
| **الفتح** | رمز من 4 أرقام — ثانيتان |
| **المحتوى خلفه** | **مضبَّب تمامًا** — لا يُقرأ اسم مريض ولا نص |
| **بعد الفتح** | العودة إلى **نفس الشاشة ونفس الحقل ونفس موضع المؤشر** |
| **ما كُتب ولم يُحفظ** | مستحيل — كل شيء محفوظ أصلًا |
| **القفل اليدوي** | `⌘L` أو زر في الشريط العلوي |
| **مدة الخمول** | من الإعدادات · افتراضيًا 3 دقائق للطبيب، 15 للسكرتيرة |
| **نسيان الرمز** | يُفتح بكلمة المرور الكاملة |

# 3 · البحث الشامل

**ليس شاشة — طبقة تُفتح من أي مكان بـ`⌘K` أو بالنقر على حقل البحث الدائم.**

```
┌────────────────────────────────────────────────┐
│ 🔍 نبيل                                        │
├────────────────────────────────────────────────┤
│ المرضى                                         │
│   سامر الأحمد        ٤٢ سنة · ٠٩٩١٢٣٤٥٦٧        │
│   نبيل حداد        ٣٥ سنة · ٠٩٩٨٨٨٨٨٨٨        │
│                                                │
│ التشخيصات (للطبيب فقط)                         │
│   فتق إربي — ١٢ مريضًا                         │
│                                                │
│ أفعال سريعة                                    │
│   + مريض جديد باسم «نبيل»                      │
└────────────────────────────────────────────────┘
```

### القواعد

| البند | القاعدة |
|---|---|
| **البحث أثناء الكتابة** | نتائج فورية من الحرف الثاني |
| **يفهم الرقم** | كتابة `0991` تبحث في الهواتف |
| **يفهم المزيج** | `نبيل 0991` = اسم + رقم معًا |
| **يتجاهل التشكيل والهمزات** | `احمد` تجد `أحمد` |
| **`Enter`** يفتح الأول | و`↑↓` للتنقل |
| **`Esc`** يغلق ويعيدك لمكانك | بلا فقدان شيء |
| **صلاحيات** | السكرتيرة تبحث في المرضى فقط. الطبيب في كل شيء |

**الفعل السريع الأهم:** إن لم يوجد المريض، يظهر مباشرة `+ مريض جديد باسم «نبيل»` — فالبحث الفاشل يتحول إلى إنشاء ناجح بنقرة.

# 5 · سجل الأحداث

**للطبيب حصرًا. لا يُحذف ولا يُعدَّل — ولا حتى منك.**

```
┌─ سجل الأحداث ──────── [الكل ▾] [اليوم ▾] ─────┐
│                                               │
│ ٩:٤٢  السكرتيرة  قبضت ٣٠٬٠٠٠ من ريم خوري      │
│                  (المستحق ٥٠٬٠٠٠ · ناقص)      │
│ ٩:٣٨  الطبيب     أنهى زيارة سامر الأحمد         │
│ ٩:١٥  السكرتيرة  ألغت موعد سامر حلاق          │
│ ٨:٠٥  السكرتيرة  سجلت الدخول                  │
└───────────────────────────────────────────────┘
```

**المرشحات:** حسب المستخدم · حسب النوع (مالي، مواعيد، طبي، دخول) · حسب التاريخ.

**الاستخدام الواقعي:** لن يُفتح يوميًا. يُفتح حين يظهر سؤال: «متى ألغي هذا الموعد؟» أو «من عدّل هذا المبلغ؟» — وحينها يجب أن يجيب فورًا.

### 6.1 الوصفة الطبية

**الحجم:** A5 — الحجم المعتاد للوصفات، واقتصادي في الورق.

```
                    الوصفة

  ١·  أوغمنتين ١ غ  (Augmentin)
      حبة مرتين يوميًا لمدة أسبوع

  ٢·  بروفين ٦٠٠
      حبة ثلاث مرات يوميًا بعد الطعام · ٥ أيام

  ٣·  أوميبرازول ٢٠
      حبة صباحًا على الريق · ١٠ أيام

  ─────────────────────────────────
  ملاحظات: تجنب رفع الأثقال أسبوعين
```

| البند | القاعدة |
|---|---|
| **اسم الدواء** | بارز · عربي أو لاتيني أو الاثنان حسب اختيارك لكل دواء |
| **الجرعة** | **بالعربية دائمًا** — «حبة مرتين يوميًا» لا `1x2` |
| **الترقيم** | أرقام عربية-هندية للترتيب |
| **المسافة بين الأدوية** | واسعة — الصيدلي يقرأ بسرعة، والازدحام يولّد الخطأ |
| **الفراغ السفلي** | لكتابة يدوية إن لزم |

### 6.2 طلب التحاليل والأشعة

**الحجم:** A5.

```
                 طلب فحوص

  المطلوب:
  ▫  تعداد دم كامل CBC
  ▫  زمن البروترومبين PT / INR
  ▫  وظائف كلية
  ▫  إيكو بطن

  ─────────────────────────────────
  التشخيص المبدئي: فتق إربي أيمن
  ملاحظة: صائم ١٢ ساعة
```

**تفصيل مهم:** التشخيص المبدئي يُطبع لأن المخبر ومركز الأشعة يحتاجانه — لكنه **حقل اختياري يمكنك حذفه** من المطبوعة إن كان حساسًا.

### 6.3 التقرير الطبي / الإفادة

**الحجم:** A4 — يذهب لجهة رسمية.

```
                 تقرير طبي

  المريض: سامر الأحمد · ٤٢ سنة
  رقم الملف: ١٢٤٧
  التاريخ: ٨ آب ٢٠٢٦

  الشكوى:
  ______________________________________

  الفحص:
  ______________________________________

  التشخيص:
  ______________________________________

  الإجراء المتخذ:
  ______________________________________

  التوصيات:
  ______________________________________

                      د. [اسم الطبيب]
                      اختصاصي جراحة عامة
                      التوقيع والختم
```

| البند | القاعدة |
|---|---|
| **يُبنى من الزيارة تلقائيًا** | الحقول معبأة مما كتبته، ثم تحرره قبل الطباعة |
| **قابل للتحرير الكامل** | التقرير للجهة الرسمية قد يختلف عما في السجل |
| **قوالب جاهزة** | «إفادة مرضية»، «تقرير ما بعد عملية»، «إحالة» |
| **نسخة محفوظة** | كل تقرير مطبوع يُحفظ في ملف المريض |

### 7.1 الترويسة المطبوعة من النظام

**المكسب:** تغيّر العنوان أو الهاتف أو تضيف تخصصًا في الإعدادات — ويتغير كل مطبوع فورًا، بلا رمي مئات الأوراق الجاهزة.

**تصميم الترويسة:**

```
┌───────────────────────────────────────────────┐
│  ▢          عيادة الدكتور [اسم الطبيب]     │
│ شعار        اختصاصي جراحة عامة                │
│             حماة — العنوان · ٠٩٩x xxx xxx     │
│  ═════════════════════════════════════════    │  ← خط رفيع
└───────────────────────────────────────────────┘
```

| البند | القاعدة |
|---|---|
| **الشعار** | يمين الترويسة (بداية القراءة في RTL) · ارتفاع 18 مم |
| **اسم العيادة** | 16 نقطة · SemiBold |
| **التخصص** | 11 نقطة · رمادي |
| **العنوان والهاتف** | 9.5 نقطة · رمادي |
| **الخط الفاصل** | 0.7 مم · أسود خفيف |
| **الارتفاع الكلي** | 28 مم في A5 · 32 مم في A4 |
| **معاينة حية** | في الإعدادات، ترى الترويسة كما ستُطبع أثناء تعديلها |

**⚠ ضبط تنفيذي للمرحلة 8:** الطابعات تختلف في الهامش غير القابل للطباعة. سيتضمن النظام **صفحة معايرة** تُطبع مرة واحدة لضبط الهوامش بدقة على طابعتك.

### 7.2 رقم الملف

| البند | القاعدة |
|---|---|
| **التوليد** | تلقائي عند إنشاء المريض · تسلسلي · لا يتكرر أبدًا |
| **البداية** | 1 — أو رقم تختاره إن أردت البدء من 1000 مثلًا |
| **لا يُعاد استخدامه** | مريض مؤرشف يحتفظ برقمه للأبد |
| **في المطبوعات** | أعلى يسار بيانات المريض: `رقم الملف: 1247` |
| **في البحث** | كتابة `1247` تجد المريض مباشرة |
| **في الواجهة** | يظهر خافتًا بجانب الاسم — لا يزاحمه |

**فائدة عملية:** إن احتفظت بملفات ورقية أو مغلفات أشعة، الرقم يربط الورقي بالرقمي بلا لبس بين متشابهي الأسماء.

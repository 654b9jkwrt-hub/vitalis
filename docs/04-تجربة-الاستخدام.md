# المرحلة 4 — تصميم تجربة الاستخدام

**المشروع:** نظام إدارة عيادة جراحة عامة
**الحالة:** مسودة للمراجعة — لم تُعتمد بعد
**يبني على:** المراحل 1–3 — معتمدة

> هذه المرحلة تصمم **سلوك** النظام وبنية التنقل فيه.
> الشكل البصري (ألوان، خطوط) في المرحلة 5. الشاشات بتفاصيلها في المرحلة 6.

## 2. النموذجان الذهنيان

هذا أساس كل ما يلي. المستخدمان لا يفكران بالطريقة نفسها إطلاقًا:

| | الطبيب | السكرتيرة |
|---|---|---|
| **السؤال الذي يعيش فيه** | «من أمامي الآن؟» | «كيف يسير اليوم؟» |
| **وحدة تفكيره** | المريض | اليوم |
| **شكل عمله** | عمق: مريض واحد باهتمام كامل | اتساع: عشرة أشياء متوازية |
| **مدة الجلسة** | دقائق متقطعة | ساعات متصلة |
| **أسوأ ما يصيبه** | أن يخرجه النظام من سياق المريض | أن تضيع منها معلومة وسط المقاطعات |
| **لذلك شاشته الرئيسية** | **ملف المريض** | **لوحة اليوم** |

## 3. البنية التنقلية

### 3.1 واجهة الطبيب — «مساحة واحدة، لا برنامج بنوافذ»

```
┌────────────────────────────────────────────────────────────┐
│  🔍 بحث…                    سامر الأحمد · 42 سنة    [إشعارات] │  ← شريط رفيع دائم
├──────────┬─────────────────────────────────────────────────┤
│          │                                                 │
│  اليوم   │                                                 │
│  ───────  │            ملف المريض                          │
│  ٩:٠٠ ✓  │            (المساحة الرئيسية)                   │
│  ٩:٣٠ ●  │                                                 │
│ ١٠:٠٠    │                                                 │
│ ١٠:٣٠    │                                                 │
│          │                                                 │
│ ───────  │                                                 │
│ تحتاج    │                                                 │
│ انتباهك ③│                                                 │
│          │                                                 │
└──────────┴─────────────────────────────────────────────────┘
```

**ثلاثة عناصر فقط، لا رابع:**

1. **شريط علوي رفيع** — البحث، اسم المريض المفتوح، الإشعارات. لا قوائم منسدلة.
2. **عمود جانبي ضيق** — قائمة اليوم + عدّاد المعلّقات. قابل للطي بمفتاح واحد.
3. **المساحة الرئيسية** — ملف المريض. **هذا هو التطبيق.**

**القاعدة الحاكمة:** الطبيب لا «ينتقل بين صفحات». هو في مكان واحد، ومحتواه يتغير. لا شاشة «المرضى» ولا شاشة «الزيارات» ولا شاشة «الوصفات» — كلها تحدث **داخل** ملف المريض.

**ما لا يظهر على شاشة الطبيب إطلاقًا:** المالية التفصيلية، الإعدادات، التقارير. هذه تُفتح عند الحاجة في مساحة مؤقتة تُغلق بـEsc وتعيدك إلى حيث كنت بالضبط.

### 3.2 ملف المريض — ترتيب المحتوى

الترتيب من أعلى لأسفل مقصود، مبني على تحليل المرحلة 1:

```
┌─ الرأس ────────────────────────────────────────┐
│ سامر الأحمد · 42 سنة · ٠٩٩١٢٣٤٥٦٧                │
│ ⚠ حساسية بنسلين   ⚠ مميعات دم                  │  ← لا تُطوى أبدًا
├─ الحالة النشطة ────────────────────────────────┤
│ 📁 فتق إربي أيمن · مفتوحة منذ ٢٠ يومًا          │
├─ آخر زيارة ────────────────────────────────────┤
│ ٢٤ تموز — مراجعة                               │
│ «طلبت تحاليل ما قبل العملية. يراجع بالنتائج»   │  ← أول ما تراه العين
│ ⏳ طلب خارجي معلّق: لم تصل النتيجة             │
├─ الزيارة الجارية ──────────────────────────────┤
│ [محرر الزيارة — يُفتح تلقائيًا عند الاستدعاء]   │
├─ ما قبلها ─────────────────────────────────────┤
│ ▸ ١٠ تموز — كشف                                │
│ ▸ ٢ حزيران — زيارة قصيرة (ضماد)                │
└────────────────────────────────────────────────┘
```

**قرار تصميمي:** «آخر زيارة» تظهر **مفتوحة ومقروءة**، وكل ما قبلها مطوي في سطر واحد. هذا يحل مباشرة نقطة الاحتكاك رقم 3 من المرحلة 1 («ماذا قلت لهذا المريض آخر مرة؟») بصفر نقرات.

**التحذيرات الطبية (الحساسية، المميعات)** لا تُطوى ولا تُخفى ولا تحتاج نقرة. للجراح تحديدًا، هذه معلومة لا يجوز أن تكون على بعد نقرة.

### 3.3 واجهة السكرتيرة — «لوحة اليوم»

```
┌────────────────────────────────────────────────────────────┐
│  🔍 ابحث باسم أو رقم…                        [+ مريض جديد] │
├──────────┬─────────────────────────────────────────────────┤
│          │  اليوم — السبت ٨ آب            ٧ مرضى · ٣ انتهوا│
│ ● اليوم  │  ─────────────────────────────────────────────  │
│ 📅 التقويم│  ● في الانتظار (٢)                             │
│ ☎ اتصالات│    سامر الأحمد    ٩:٣٠   مراجعة    منذ ١٢ د       │
│ 💰 الصندوق│    سلمى حداد    ١٠:٠٠  كشف      منذ ٤ د        │
│ 📋 الديون │  ─────────────────────────────────────────────  │
│          │  ◐ عند الطبيب (١)                              │
│          │    أحمد عيسى    ٩:٠٠   ضماد                    │
│          │  ─────────────────────────────────────────────  │
│          │  ⚠ انتهى — لم يُحاسب (١)                        │
│          │    ريم خوري     ٨:٣٠   كشف     ٥٠,٠٠٠ [قبض]    │
│          │  ─────────────────────────────────────────────  │
│          │  ○ لم يصل بعد (٣)                              │
└──────────┴─────────────────────────────────────────────────┘
```

**مبدأ التصميم:** الشاشة تجيب عن سؤالها الأول («كيف يسير اليوم؟») **بلا نقرة واحدة**.

**خمس حالات فقط لكل مريض:** لم يصل → في الانتظار → عند الطبيب → انتهى ولم يُحاسب → خرج.

**الحالة الحرجة هي الرابعة.** «انتهى ولم يُحاسب» هي أكثر ما يُنسى في العيادات، ولهذا تحمل علامة تحذير وتُعرض قبل من لم يصل بعد. المبلغ ظاهر بجانب الاسم وزر القبض إلى جواره مباشرة — **قبض المال من هنا: نقرة واحدة.**

**وجها المواعيد منفصلان** كما اكتُشف في المرحلة 1: «اليوم» للتنفيذ، «التقويم» للتخطيط.

## 4. المسودة الحية — حل الكتابة المختلطة

هذا أهم نظام في التجربة، وهو جواب قرارك ㉖.

### المشكلة

تكتب سطرين وأنت تتحدث مع المريض، ثم تفحصه، ثم يخرج، ثم تُكمل. وبينهما قد يدخل مريض طارئ. أي نظام يطلب «حفظ» أو «إلغاء» سيخسر منك شيئًا في مكان ما.

### الحل

| القاعدة | التفصيل |
|---|---|
| **الزيارة تُنشأ تلقائيًا** | لحظة استدعاء المريض. لا زر «زيارة جديدة» |
| **كل حرف يُحفظ فورًا** | **لا يوجد زر حفظ في النظام كله** |
| **لا يوجد إلغاء** | يوجد **تراجع** (Undo). الإلغاء يخسر، والتراجع لا يخسر |
| **الزيارة تبقى مسودة** | حتى تضغط «إنهاء الزيارة» صراحةً |
| **الخروج لا يُغلق شيئًا** | افتح مريضًا آخر، عد بعد ساعة، ستجد المسودة كما تركتها بالحرف |
| **المسودة المنسية تُلاحقك** | زيارة بقيت مسودة بعد انتهاء الدوام ← تظهر في «تحتاج انتباهك» |

**قاعدة الأمان الأخيرة:** إن أُقفل اليوم وفيه مسودات مفتوحة، ينبهك النظام قبل الإقفال. لا يمنعك — بل يخبرك.

## 5. بطاقة الاختتام — «قرار واحد يولّد كل شيء»

من المرحلة 1، لحظة الحقيقة الثانية: *إنهاء المعاينة يجب أن يولّد تلقائيًا الوصفة والموعد والمبلغ والطباعة.*

عند ضغط «إنهاء الزيارة» تظهر **بطاقة واحدة** فيها أربعة أسطر:

```
┌─ إنهاء زيارة: سامر الأحمد ───────────────────────┐
│                                                │
│  💊 الوصفة          [+ إضافة]     ← اختياري    │
│  🧪 طلبات خارجية    [+ إضافة]     ← اختياري    │
│  📅 الموعد القادم   [بعد أسبوع ▾] ← مقترح      │
│  💰 المبلغ المستحق  [٥٠,٠٠٠  ]    ← إلزامي     │
│                                                │
│         [إنهاء وطباعة]        [إنهاء فقط]      │
└────────────────────────────────────────────────┘
```

**قواعد البطاقة:**

1. **المبلغ إلزامي** — تنفيذًا لاكتشاف المرحلة 1 (§8.1): سعرك يدوي، ونسيانه يشلّ السكرتيرة أمام المريض. النظام يقترح آخر مبلغ استخدمته لحالة مشابهة، ويقبل الصفر (مجانًا) لكنه لا يقبل الفراغ.
2. **الموعد القادم مقترح لا مفروض** — يظهر اقتراح ذكي («بعد أسبوع»، «بعد نزع القطب بـ7 أيام») ويمكن رفضه.
3. **زر واحد ينهي كل شيء** — يُغلق الزيارة، يطبع ما يجب طباعته، يُرسل المستحق للسكرتيرة، ويعيدك إلى قائمة اليوم.
4. **البطاقة تُغلق بـEsc** — والزيارة تبقى مسودة سليمة.

**هذه البطاقة هي قلب النظام.** إن نجحت، نجح النظام.

## 6. قاعدة الثلاث نقرات — التطبيق الفعلي

شرطك الأهم. هذا جدول تدقيق سأُقاس عليه في المرحلة 6:

### الطبيب

| المهمة | النقرات | كيف |
|---|---|---|
| فتح المريض التالي | **1** | من عمود اليوم |
| قراءة ما قلته آخر مرة | **0** | ظاهر في الملف |
| رؤية الحساسيات والتحذيرات | **0** | ظاهرة دائمًا |
| بدء كتابة المعاينة | **0** | المحرر مفتوح تلقائيًا |
| كتابة وصفة من قالب | **2** | اختتام ← اختيار القالب |
| كتابة وصفة من أدوية مفردة | **3** | اختتام ← إضافة ← اختيار الدواء |
| طلب تحاليل | **2** | اختتام ← اختيار من قوالبك |
| إنهاء الزيارة كاملة مع الطباعة | **2** | إنهاء ← إنهاء وطباعة |
| تسجيل زيارة قصيرة (ضماد) | **2** | فتح المريض ← «ضماد» ← تم |
| معرفة من ينتظر | **0** | ظاهر في العمود |
| رؤية المعلّقات | **1** | من العمود |
| معرفة دخل اليوم | **1** | من الإشعارات/الصندوق |
| البحث عن مريض قديم | **1** + كتابة | البحث الدائم |
| تسجيل إجراء صغير أثناء الزيارة | **2** | داخل المحرر، بلا مغادرة |

### السكرتيرة

| المهمة | النقرات | كيف |
|---|---|---|
| معرفة حالة اليوم | **0** | لوحة اليوم |
| تسجيل حضور مريض | **1** | من قائمة اليوم |
| قبض مبلغ | **1** | زر بجانب الاسم |
| حجز موعد لمريض قديم | **2** | بحث ← اختيار وقت |
| إنشاء مريض جديد + موعد | **1** + كتابة اسم وهاتف | زر «+ مريض جديد» |
| معرفة من عليه دين | **1** | من الشريط |
| قائمة اتصالات الغد | **1** | من الشريط |
| إقفال اليوم | **2** | الصندوق ← إقفال |

**⚠ أثقل مسار في النظام:** كتابة وصفة من أدوية مفردة = 3 نقرات + كتابة لكل دواء. هذا هو السقف، ولن يُتجاوز.

## 7. الإشعار الصامت — التصميم التفصيلي

وعدتُ في المرحلة 1 بتصميمه بعناية. المعادلة: **إن كان ملفتًا أزعج، وإن كان خافتًا أُهمل.**

| الخاصية | القرار | السبب |
|---|---|---|
| **الموضع** | الزاوية السفلية اليسرى (بعيدًا عن مسار القراءة في RTL) | لا يعترض النص |
| **الظهور** | انزلاق هادئ خلال جزء من ثانية | الحركة المفاجئة تسرق الانتباه |
| **الصوت** | لا صوت إطلاقًا | أنت أمام مريض |
| **الحجب** | لا يحجب شيئًا، ولا يسرق التركيز من حقل تكتب فيه | القاعدة الحاكمة |
| **المدة** | يبقى 6 ثوانٍ ثم ينزوي | كافٍ للنظرة، غير كافٍ للإزعاج |
| **بعد الانزواء** | يتحول إلى نقطة ملوّنة على أيقونة الإشعارات | لا يضيع |
| **التراكم** | «٣ إشعارات جديدة» لا ثلاث بطاقات | لا تُغرق الشاشة |
| **الفقدان** | مستحيل — كلها في سجل دائم | الضمانة الحقيقية |
| **أثناء الكتابة** | يُؤجَّل حتى تتوقف عن الكتابة | لا يقاطع تدفق الفكر |

**محتواه:** `ريم خوري · المستحق ٥٠٬٠٠٠ · قُبض ٣٠٬٠٠٠ · الفرق ٢٠٬٠٠٠`
سطر واحد. لا أزرار. لا يطلب منك شيئًا. **يخبر فقط.**

## 8. قواعد سلوكية عامة

### 8.1 لا فقدان للعمل

| المبدأ | التطبيق |
|---|---|
| لا زر «حفظ» | كل شيء يُحفظ فور كتابته |
| لا رسالة «هل تريد الحذف؟» | احذف فورًا + أظهر «تم الحذف — [تراجع]» لعشر ثوانٍ |
| لا حذف حقيقي | أرشفة قابلة للاسترجاع |
| القفل يحفظ | تعود إلى نفس الحقل ونفس الكلمة |
| انقطاع الشبكة | جهاز الطبيب يواصل العمل ويزامن عند العودة (تفاصيله في المرحلة 8) |

**الأساس:** الرسائل التأكيدية (`هل أنت متأكد؟`) وهم أمان — تُضغط تلقائيًا بلا قراءة بعد أسبوع. **التراجع أصدق من التأكيد.**

### 8.2 اللغة والاتجاه

- **RTL كامل**: التخطيط من اليمين لليسار، والحركة والانتقالات كذلك.
- **الأرقام**: 1234 (إنجليزية) — أوضح في القراءة السريعة للمبالغ، ومطابقة لما يُكتب على الأوراق في سوريا.
- **التواريخ**: ميلادية بالأسماء العربية (٨ آب ٢٠٢٦).
- **لا مصطلحات تقنية**: لا «سجل»، لا «كيان»، لا «إدخال بيانات». اللغة لغة عيادة: مريض، زيارة، وصفة، موعد، دفعة.

### 8.3 رسائل النظام

| بدلًا من | نقول |
|---|---|
| «خطأ في العملية» | «لم يُحفظ الموعد — الوقت محجوز لمريض آخر» |
| «حقل إلزامي» | «نحتاج اسم المريض ورقمه فقط» |
| «تمت العملية بنجاح» | لا شيء — أظهر النتيجة نفسها |

**قاعدة:** كل رسالة خطأ تقول **ما حدث** و**ما العمل**. والرسائل الناجحة لا تُكتب أصلًا — بل تُرى نتيجتها.

### 8.4 الشاشات الفارغة

عيادة جديدة تعني أن كل شاشة ستكون فارغة في اليوم الأول. الشاشة الفارغة ليست خطأً — هي **أول درس** يتعلمه المستخدم.

مثال: قائمة اليوم فارغة ← «لا مواعيد اليوم. [+ أضف موعدًا]» — لا صورة حزينة ولا نص طويل.

### 8.5 الاختصارات

طبقة إضافية لمن يريد، **لا بديل عن الأزرار** (قرارك ㉗). ولن تُشترط معرفتها لاستخدام أي وظيفة.

| الاختصار | الفعل |
|---|---|
| `Ctrl/⌘ + K` | البحث الشامل من أي مكان |
| `Esc` | إغلاق أي طبقة والعودة لما كنت فيه |
| `Ctrl/⌘ + Z` | تراجع |
| `Ctrl/⌘ + Enter` | إنهاء الزيارة |
| `Ctrl/⌘ + L` | قفل الشاشة فورًا |
| `↑ ↓` | التنقل في قوائم الاقتراحات |

كل اختصار مكتوب بجانب الزر المقابل له، فيتعلمه المستخدم بالمصادفة لا بالحفظ.

### 10.1 ترتيب الدور اليدوي

**التصميم:**

| البند | القرار |
|---|---|
| **الترتيب الافتراضي** | حسب وقت الموعد — لا تبدأ السكرتيرة من فراغ |
| **إعادة الترتيب** | سحب الاسم لأعلى أو لأسفل. وأيضًا سهمان صغيران لمن لا يحب السحب |
| **من وصل بلا موعد** | يُضاف في نهاية قائمة الواصلين، ثم تحركه هي |
| **ما يراه الطبيب** | ترتيبها بالضبط. المريض التالي هو أول من في القائمة، دائمًا |
| **مؤشر التأخير** | «ينتظر منذ ٢٥ دقيقة» بجانب الاسم — معلومة تساعدها على العدل بلا أن يفرض النظام رأيه |
| **حالة خاصة** | إن حرّكت مريضًا فوق آخر ينتظر منذ وقت أطول، لا يعترض النظام — هي ترى الصالة ولا يراها |

**تحليل:** هذا القرار أذكى مما يبدو. القاعدة الآلية (وقت الوصول أو وقت الموعد) عمياء دائمًا: لا تعرف أن هذا المريض مسنّ متعب، ولا أن ذاك جاء من قرية بعيدة، ولا أن الثالث يحتاج دقيقتين فقط لنزع قطب. **السكرتيرة تملك معلومات لا يملكها أي نظام.** دورنا أن نعطيها أداة سحب مريحة، لا أن نفرض عليها منطقًا.

### 10.2 لوح الالتقاط — الكتابة الحرة أثناء الفحص

هذا يعيد تصميم محرر الزيارة. الشكل المعتمد:

```
┌─ الزيارة الجارية ──────────────────────────────┐
│                                                │
│  ✎ التقاط سريع                                 │
│  ┌──────────────────────────────────────────┐  │
│  │ ألم بطن يمين سفلي منذ ٣ أيام            │  │
│  │ حرارة ٣٧.٨                               │  │
│  │ إيلام بالجس + ماكبرني إيجابي            │  │
│  │ شك بالتهاب زائدة                        │  │
│  └──────────────────────────────────────────┘  │
│                                                │
│  ▸ الحقول المنظمة (فارغة)                      │
│                                                │
└────────────────────────────────────────────────┘
```

**كيف يعمل:**

| المرحلة | ما يحدث |
|---|---|
| **أثناء الفحص** | تكتب في اللوح بحرية تامة. لا حقول، لا تنقّل، لا تفكير في التصنيف |
| **بعد خروج المريض** | يظهر بجانب كل سطر أربعة أزرار صغيرة: **شكوى · فحص · تشخيص · خطة** |
| **التوزيع** | نقرة واحدة على السطر تُرسله إلى حقله |
| **إن لم توزّع** | **النص يبقى كما هو ويُحفظ ضمن الزيارة كاملًا.** لا يضيع حرف |

**القاعدة الحاكمة — وهي الأهم:** اللوح **يصلح وحده كسجل كامل** إن لم توزّع شيئًا أبدًا. التوزيع ترقية اختيارية، لا شرط لإغلاق الزيارة.

**الاستثناء الوحيد — التشخيص:** لأنك اخترت إحصاء الأنماط الطبية (⑮)، يحتاج النظام تشخيصًا منظّمًا واحدًا على الأقل. الحل الخفيف: عند الاختتام، إن لم يُوزَّع تشخيص، يقرأ النظام آخر سطر ويعرض اقتراحًا واحدًا صغيرًا: «التشخيص: التهاب زائدة؟» — تقبله بنقرة أو تتجاهله. **لا يمنعك من الإنهاء.**

**تحديث قاعدة النقرات:** كتابة معاينة كاملة عبر اللوح = **كتابة حرة + 4 نقرات توزيع**، مقابل التنقل بين أربعة حقول أثناء وجود المريض. هذا مكسب حقيقي في وقت النظر إلى الشاشة.

### المبادئ المضافة

10. **لا تفرض منطقًا على من يملك معلومات أكثر منك.** السكرتيرة ترى الصالة، والنظام لا يراها.
